# Evolution X for Exynos 9810

Unofficial bring-up workspace for the Exynos 9810 Samsung Galaxy S9 (`starlte`), S9+ (`star2lte`), and Note 9 (`crownlte`).

The repository was empty when work began. The active Android 17 bring-up is maintained on `bringup/evolutionx-cnb`; see that branch for the local manifest, product makefiles, scripts, and build instructions.
